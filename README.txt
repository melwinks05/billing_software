# Elan LED Enterprises Billing Software

A simple browser-based A4 billing/estimate application made with HTML, CSS and JavaScript.

## Run

Open `index.html` in Google Chrome or Microsoft Edge.

No Node.js, Python server, database, or internet connection is required.

## Features

- Estimate / Tax Invoice / Delivery Challan dropdown
- Tax Invoice changes the customer label to Bill To
- Separate editable Shipping Address
- Automatic document numbering (`EST-0001`, `EST-0002`, ...)
- Customer details
- Editable item name, HSN/SAC, quantity, rate and GST %
- Automatic GST split into CGST and SGST
- Amount in words
- Bank/payment section
- Print / Save as PDF using browser print
- Saved bills using browser localStorage
- Load/delete previous bills
- A4 print layout
- Uploaded Elan LED logo included

## Important

Saved bills are stored only in the browser on the computer where the application is used. Clearing browser site data can remove them. There is no database in this version.

The GSTIN and business information in the application are kept exactly as supplied and should be verified before using the software for real invoices.
